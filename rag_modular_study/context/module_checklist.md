# Context Synthesis Checklist

- [ ] Raw Concatenation (Nối chuỗi cơ bản)
- [ ] Structured FAQ Markdown (Định dạng Q&A, bảng biểu)
- [ ] Token Budget Truncation (Cắt gọt theo ngân sách token)
- [ ] Citation & Article Tagging (Đánh số [Điều X, Khoản Y])
- [ ] Lost-in-the-Middle Context Reordering (Đảo vị trí chunk quan trọng)
- [ ] Extractive Summarization / Pruning (LLMLingua)
- [ ] Duplicate Chunk Deduplication (Cosine Threshold Filter)
