# Biometric Compliance Audit QĐ 2345 & TT 50

## Instructions

1. Clarify transaction value, daily cumulative total, and device status if they can alter the outcome. Do not assume an authenticated status for the customer.
2. Use tools to cross-check with known parameters. When answering about applicable regulations, look up internal sources and cross-reference conditions with tool outputs.
3. Separate conclusions by each condition. When data is lacking, ask back or clearly state the portion that cannot be cross-checked.

Never request OTP, PIN, CVV, or full identification numbers. Cross-checking results do not alter transaction or authentication status.
